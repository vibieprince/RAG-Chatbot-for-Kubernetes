01 // RECRUITER EXECUTIVE OVERVIEW

Designed for Cluster Administrators & DevOps Engineers

The platform enables engineering teams to query Kubernetes manifests, Pod autoscaling behaviors, and defensive security configurations through a safe, conversational interface.

01

Defense-in-Depth AI Safety

User inputs pass through Unicode NFKC normalization, base64 payload extraction, regex heuristics (<2ms), and Groq SLM domain policy verification before reaching the agent. Retrieved docs are isolated to block indirect prompt injections.

02

Two-Stage Hybrid Retrieval

Combines high-recall Qdrant vector search (15 candidates) with an in-process quantized ONNX cross-encoder (FlashRank ms-marco-MiniLM-L-6-v2) for top-5 precision, eliminating bi-encoder false positives on complex flags.

03

Zero-Downtime Resilience & SSE

OpenAI-compatible LiteLLM proxy container routes primary models with automatic failover to direct AsyncGroq inference. Delivers live tokens over Server-Sent Events with single-generation efficiency.

05 // ENGINEERING DEEP DIVE

Documented Engineering Decisions & Subsystems

Explore the core technical mechanisms actually implemented in the codebase: two-stage retrieval, agentic state machines, resilient inference gateways, and universal multi-format ingestion.

Stage 1 Recall (Qdrant) + Stage 2 Precision (FlashRank Cross-Encoder)

Bi-encoders calculate cosine similarity between independent vector embeddings, which struggles with nuanced syntax (e.g. distinguishing subtle flag differences in kubectl or Ingress annotations). We couple broad Qdrant recall with local in-process cross-attention reranking.

Stage 1: Qdrant Dense Similarity Search

  • Interface: Modern query_points API over collection enterprise_rag
  • Candidate Recall: Retrieves 15 raw document chunks with payload text and scores
  • Dual Embeddings: Primary Google Gemini gemini-embedding-2-preview (3072-dim) with 4-stage backoff; local CPU fallback all-mpnet-base-v2 (768-dim)

Stage 2: FlashRank Local CPU Cross-Encoder

  • Model: Quantized ONNX ms-marco-MiniLM-L-6-v2 executing locally on CPU
  • Cross-Attention: Joint token evaluation of query and candidate passage simultaneously
  • Top-N Selection: Reranks and filters 15 candidates down to top 5 high-precision passages
  • Degradation: Falls back safely to Qdrant cosine ordering if ONNX engine throws

LangGraph Cyclic StateGraph & MemorySaver Checkpointing

The agentic workflow in app/agents/graph.py implements a LangGraph cyclic state machine. The planner dynamically evaluates whether an inquiry requires documentation retrieval or conversational memory synthesis, saving 500ms+ latency on conversational turns. 

workflow = StateGraph(AgentState)
workflow.add_node("planner", planner_node)
workflow.add_node("retriever", retriever_node)
workflow.add_node("responder", responder_node)

workflow.set_entry_point("planner")
workflow.add_conditional_edges(
    "planner",
    route_intent,
    { "retrieve": "retriever", "respond": "responder" }
)
workflow.add_edge("retriever", "responder")
workflow.add_edge("responder", END)

checkpointer = MemorySaver()
rag_agent = workflow.compile(checkpointer=checkpointer)

True End-to-End Server-Sent Events (SSE) Protocol

The streaming pipeline in app/services/streaming.py emits structured SSE frames. It completely resolves legacy double-generation bugs by invoking the streaming inference provider exactly once.

Universal Multi-Format Ingestion Engine

The ingestion engine in app/ingestion/processor.py parses technical documentation across 5 distinct formats, performs semantic recursive chunking (800 chars / 150 overlap), caches JSON metadata locally, and upserts points to Qdrant.

Format Loaders

PDF (pypdf, pdfplumber), HTML (BeautifulSoup4), Word (python-docx), PowerPoint (python-pptx), and plain UTF-8 text.

Semantic Chunking

LangChain RecursiveCharacterTextSplitter with 800-character chunk sizes and 150-character overlaps preserving manifest blocks.

Local JSON Caching

Extracted passages and source metadata are cached in processed_data/<source>/<file>.json for offline auditing.

Production Nginx Reverse Proxy Configuration (Disabling SSE Buffering)

When placing a reverse proxy (Nginx, Traefik, Ingress) in front of the FastAPI streaming endpoint, buffering must be disabled to ensure instantaneous token transport. FastAPI emits X-Accel-Buffering: no by default: 

location /query/stream {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Connection '';
    proxy_http_version 1.1;
    chunked_transfer_encoding off;
    proxy_buffering off;
    proxy_cache off;
}
